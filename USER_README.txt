Todo List — Windows 桌面版
==========================

无需安装 Python，无需打开浏览器。

[安装]
  1. 运行 TodoList-Setup.exe，按向导完成安装
  2. 从开始菜单或桌面快捷方式启动「Todo List」

[便携版]
  也可直接双击 TodoList.exe（无需安装）

[数据]
  数据库与附件保存在程序目录下的 data 文件夹
  备份：复制整个 data 文件夹

[卸载]
  设置 → 应用 → 卸载「Todo List」
  卸载不会自动删除 data，如需清除请手动删除安装目录下的 data

[局域网]
  在安装目录打开命令行运行：
  TodoList.exe --host 0.0.0.0
  其他电脑访问 http://本机IP:5050

[系统要求]
  Windows 10 / 11（64 位）
  需已安装 Microsoft Edge WebView2（Win10/11 通常已自带）
