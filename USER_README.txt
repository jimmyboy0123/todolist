Todo List - User Guide
======================

No Python needed. No installation. Just run the exe.

[Run]
  Double-click TodoList.exe
  Browser opens automatically.

[Data]
  Database: data\todo.db (created next to the exe on first run)
  Backup: copy the whole data folder

[Stop]
  Close the black console window

[LAN access]
  Run from cmd: TodoList.exe --host 0.0.0.0
  Others visit http://YOUR-PC-IP:5050

[System]
  Windows 10 / 11 (64-bit)
